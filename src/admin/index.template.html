Signing in

This CMS edits {{REPO}}. Signing in needs a GitHub access token, which is a long password GitHub generates for you. It expires, so this needs doing again roughly once a year.

Getting a token

  1. Open this pre-filled GitHub page. Sign in to GitHub if it asks.
  2. Under Expiration, choose the longest option offered (usually 1 year), so you do not have to repeat this often.
  3. Under Repository access, choose Only select repositories and pick {{REPO_NAME}}.
  4. Under Permissions → Repository permissions, find Contents and set it to Read and write. Leave everything else alone.
  5. Click Generate token at the bottom.
  6. Copy the token it shows you. You only get to see it once.
  7. Come back here, choose Sign in using access token, and paste it in.

The token is stored only in this browser. If you use another computer, you will need to paste it there too — the same token works in both, so keep a copy somewhere safe like a password manager.

If something still will not work

  • “Bad credentials”, or signed out again: the token has expired or was revoked. Make a new one with the steps above.
  • Saving fails: the token is probably missing the Contents: Read and write permission. Make a new one and check step 4.
  • Your change saved but the site looks the same: give it two or three minutes. The site rebuilds after each save.
